# 探索者メーカー

クトゥルフ神話TRPG（第6版）の探索者をブラウザで作成できるWebアプリです。

## できること

- 時代の選択（1890年代／1920年代／現代）
- ダイスを振る演出つきの能力値決定（振り直し・手動修正も可）
- ルールブック「職業のサンプル」からの職業選択、オリジナル職業の作成
- 職業に応じた職業技能の自動設定と、技能ポイント（職業P：EDU×20／興味P：INT×10）の割り振り
- プロフィールとバックグラウンドの入力
- 探索者シートの表示、印刷、テキスト／ココフォリア駒／JSONへの出力

入力内容は使っているブラウザに自動保存されます（サーバーには送信されません）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `app.js` | 動作 |
| `data.js` | 職業・技能のデータ |

職業や技能を修正するときは `data.js` を編集してください。
